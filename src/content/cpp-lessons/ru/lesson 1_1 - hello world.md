- Как писать, компилировать и запускать "Hello, World!"

---

## Почему C++ для разработки игр?

C++ — это индустриальный стандарт для разработки игр, потому что он даёт вам:

- **Максимальную производительность** — прямой контроль над памятью без сборщика мусора
- **Доступ к железу** — работа с GPU, контроллерами и аудиоустройствами
- **Портативность** — запуск на консолях (PlayStation, Xbox, Switch), ПК и мобильных устройствах
- **Экосистему** — Unreal Engine, собственные движки и большинство AAA-студий используют C++

Если вы хотите создавать игры, которые выжимают максимум из железа, C++ — ваш язык.

## Шаг 1: Установка компилятора

Компилятор превращает ваш понятный человеку код на C++ в машинный код, который понимает компьютер.

### Windows

**Вариант A: Visual Studio Community (рекомендуется для начинающих)**

1. Скачайте [Visual Studio Community](https://visualstudio.microsoft.com/downloads/) (бесплатно)
2. Во время установки выберите **"Разработка классических приложений на C++"**
3. Нажмите Установить

**Вариант B: MinGW (лёгкий)**

1. Скачайте [MSYS2](https://www.msys2.org/)
2. Следуйте инструкции по установке
3. Откройте терминал MSYS2 и выполните:
   ```bash
   pacman -S mingw-w64-ucrt-x86_64-gcc
