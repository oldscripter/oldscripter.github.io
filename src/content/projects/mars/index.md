# Идея

Это должен быть движок без графического интерфейса. Правильнее его было бы назвать фреймворком поверх `SDL3`, который позволит оперировать высокоуровневыми абстракциями (анимация, спрайт, сцена, менеджер игровых объектов, пул ввода и т.д.) при написании кода игры на `C++`.
Движок должен быть макисмально эффективен по производительности и включать минимум сторонних зависимостей (кроме `SDL3`).

В целом на рынке уже предостаточно открытых фреймворков и движков для создания 2D игр. Целью данного проекта станет классификация и эксперимент по написанию собственного инструментария для разработки любых десктопных и кроссплатформенных приложений.

# Компоненты

- `SDL3` - основа движка - кроссплатформенная библиотека, позволяющая создавать графику, управлять пользовательским вводом и создавать мультимедийный контент.
- `С++ 20` - стандартная библиотка.
- `CMake` - кроссплатформенная система сборки

# Ключевые особенности
- Предоставляет компоненты для сборки собственных 2D игр
- Предоставляет готовые пайплайны для игрового процесса
- Имеет удобный лог
- Имеет встроенный анализатор производительности (профайлер)
